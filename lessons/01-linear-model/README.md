## 输入、训练与输出

## 核心数学

令 r_i=wx_i+b-y_i，则

\[
L(w,b)=\frac1n\sum_i r_i^2,\qquad
\partial_w L=\frac2n\sum_i r_ix_i,\quad
\partial_b L=\frac2n\sum_i r_i.
\]

链式法则的路径是参数 → 预测 → 残差 → 平方 → 平均。每条路径分别贡献导数，反向传播将贡献求和。它对实际执行的运算应用导数规则，不是有限差分，也不需要先生成符号形式的损失表达式。

初始点 (0,0) 的梯度约为 (-8.161616,-4)。所以第一次更新为

\[
(w_1,b_1)=(0,0)-0.1(-8.161616,-4)=(0.8161616,0.4).
\]

梯度为负意味着参数向正方向移动会在局部降低损失。一般对光滑函数，沿负梯度的小步有

\[
L(\theta-\eta g)=L(\theta)-\eta\|g\|^2+O(\eta^2),\quad g=\nabla L(\theta).
\]

这说明足够小的步长在非驻点可降低损失，不代表任意步长均下降，也不保证任意非凸任务达到全局最优。

本例可以精确分析：对称采样使均值 x̄=0，且

\[
a=\frac1n\sum_i x_i^2=\frac{4(n+1)}{3(n-1)}=\frac{404}{297}\approx1.36026936.
\]

代入 y=3x+2 后交叉项消失：

\[
L=a(w-3)^2+(b-2)^2,\qquad H=\operatorname{diag}(2a,2).
\]

因此损失是严格凸二次函数，唯一最小点为 (3,2)。梯度下降给出

\[
w_k-3=(1-2a\eta)^k(w_0-3),\qquad
b_k-2=(1-2\eta)^k(b_0-2).
\]

对任意初始点都收敛的充要条件（精确算术）是两个因子的绝对值都小于 1：

\[
0<\eta<\frac{2}{\lambda_{\max}(H)}=\frac1a=\frac{297}{404}\approx0.7351485.
\]

在此范围内，每个误差分量平方均缩小，因此损失下降；参数本身仍可能越过最优点来回振荡。学习率 0.1 时因子约为 0.728 与 0.8，w 的误差衰减更快。这个范围依赖当前输入尺度和损失定义；不能直接照搬到神经网络。

## 四个 PyTorch 概念

- `requires_grad=True`：w,b 是需要求导的叶张量；相关前向运算被记录，以便对它们反向求导。创建后 `.grad` 起初为 None。
- `loss.backward()`：当前 loss 是标量，反向传播计算 ∂L/∂w、∂L/∂b，并累加到叶张量的 `.grad`；不会自动进行梯度下降。
- `torch.no_grad()`：这一步只做参数的数值更新，不把优化过程加入求导图；更新后 w,b 依旧需要在下一次前向中求导。对这些叶张量直接执行被追踪的原地更新会报错。
- `.grad.zero_()`：清除本轮累加值，让下一轮只使用新梯度。梯度累积可用于多个小批次，但本实验每轮独立更新，必须清零。清零不等于将参数清零。

参考：[PyTorch 自动微分说明](https://docs.pytorch.org/docs/2.15/notes/autograd.html)、[MPS 说明](https://docs.pytorch.org/docs/2.15/notes/mps.html)。不需要进一步追踪底层实现。

## 对照实验与验证

以下均为 CPU float32、101 次更新，除初值实验外初值都是 (0,0)，其余数据保持一致。

| 学习率 | 初值 | 最终损失 | 观察 |
| --- | --- | ---: | --- |
| 0.01 | (0,0) | 0.114140 | 步长小，101 步尚未充分收敛 |
| 0.1 | (0,0) | 1.64562e-13 | 稳定收敛 |
| 0.5 | (0,0) | 0 | w 振荡收敛，b 理论上一步到位 |
| 0.7 | (0,0) | 1.86441e-8 | w 误差因子约 -0.904，振荡且比 0.5 慢 |
| 0.8 | (0,0) | 2.19932e15 | w 误差因子绝对值大于 1，发散 |
| 0.1 | (10,-8) | 1.55467e-13 | 不同初值仍收敛至同一最小点 |

历史学习率与初值对照图可在 Git 提交 `6d78f9c` 中查看。

对数轴无法显示零；绘图把零显示在 1e-16 处，CSV 中仍保留原始的零值。

`experiments.py` 实际检查了：解析梯度等于自动微分梯度；不清零且重新前向后再次 backward 得到双倍梯度；所有收敛实验的每步参数匹配闭式公式（允许浮点误差）；发散实验的 w 匹配递推，损失显著增长。

验证中第一次直接核对发散实验的 b 与精确公式失败。排查发现，当 w 增至约 4.02e7，float32 残差中的大项相消产生误差，最终 b 约 3.69，偏离精确算术下的 2。因此对该实验只核对 w 的相对误差和损失增长，不声称 b 满足精确递推，也没有简单放宽其断言来掩盖差异。

这些结果只支持当前二次函数的优化结论；没有进行神经网络训练或泛化评测。
